Testing performance for bottlenecks in system

Devices: Laptop running Ubuntu 22.04 and VM running on laptop running Debian 12

NOTE: For the division for the calculation of the average processing time per packet, 
      1 was added to each of the mean packet sizes to account for the current packet
      each time the queue length was calculated (this prevents divide by 0 problems)

Reuslts: the bottleneck almost arises from the outbound send time being slow, causing backups
         on the outbound processor queue.
